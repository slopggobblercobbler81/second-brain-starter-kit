# Ваша небольшая библиотека приёмов

В этой папке правила и четыре текстовых скилла. Их можно читать и применять
в Claude Code или Codex. Здесь нет скриптов, зависимостей или сетевого сервиса.

| Файл | Для чего |
|---|---|
| [RULES.md](RULES.md) | Границы работы помощника |
| [FIRST-TASK.md](FIRST-TASK.md) | Первая задача и проверка результата |
| [.claude/skills/lite-plan/SKILL.md](.claude/skills/lite-plan/SKILL.md) | План |
| [.claude/skills/lite-recall/SKILL.md](.claude/skills/lite-recall/SKILL.md) | Поиск прежнего решения |
| [.claude/skills/lite-check/SKILL.md](.claude/skills/lite-check/SKILL.md) | Проверка |
| [.claude/skills/lite-handoff/SKILL.md](.claude/skills/lite-handoff/SKILL.md) | Продолжение в следующем чате |

Приёмный режим означает: библиотека остаётся справочником, личные результаты
пишутся в выбранную владельцем папку вне набора. Он не является технической
блокировкой файловой системы. Агент работает только в пределах просьбы человека.
GitHub ZIP не содержит репозитория `.git` и не даёт доступа на запись в источник.

Полный первый запуск и блок для копирования: [ONBOARDING-LITE.md](../ONBOARDING-LITE.md).
Сначала одна полезная задача. Добавлять большой каталог скиллов можно позже, по потребности.
